---
title: Keyboard shortcuts
description: All keyboard shortcuts in DevMark. Cmd applies on macOS, Ctrl on Windows and Linux.
order: 1
---

| Key | Action |
|---|---|
| Cmd/Ctrl-N | New document from template |
| Cmd/Ctrl-Shift-N | New note |
| Cmd/Ctrl-Shift-J | Today's note |
| Cmd/Ctrl-Shift-F | Search notes |
| Cmd/Ctrl-O | Open |
| Cmd/Ctrl-S | Save |
| Cmd/Ctrl-W | Close tab |
| Cmd/Ctrl-\ | Toggle split |
| Cmd/Ctrl-Shift-L | Toggle list |
| Cmd/Ctrl-Shift-Enter | Focus mode |
| Cmd/Ctrl-B / I / K / E | Bold / italic / link / code |
| Cmd/Ctrl-Alt-1…3 | Heading 1–3 |
| Cmd/Ctrl-Shift-7 / 8 / 9 | Numbered list / bullet list / task list |
| Cmd/Ctrl-Shift-V | Print preview |
| Cmd/Ctrl-Shift-/ | Cheat sheet |
| Cmd/Ctrl-Shift-E | Export PDF |
| Cmd/Ctrl-Shift-T | Markdown → Typst |
