Markdown, Typst and note files appear in a serif typeface in a centered text column; code stays in monospace. Above the text you see the save state, the word count and the reading time, and for notes their `#tags`.

## Formatting

- **The formatting bar** above files and the “Format“ and “Einfügen“ (Insert) menus set headings, emphasis, lists, links and code.
- **`/` at the start of a line** opens an insert list – heading, list, table, code block and more, without typing the syntax.
- **Explanations on hover:** move the mouse over syntax to see what it does.
- **Cheat sheet** (`Cmd/Ctrl-Shift-/`) lists the most important markup.

All shortcuts are listed under [Keyboard shortcuts](../../reference/shortcuts/).

## Outline

The right margin shows one dash per heading. Click it to jump there – the quickest way through a long document.

## Templates

`Cmd/Ctrl-N` creates a new document from a template:

| Template | Contents |
|---|---|
| Artikel (article) | Technical article or blog post with title, introduction and sections |
| Bericht (report) | Title page, table of contents and numbered chapters |
| Brief (letter) | Business letter (DIN 5008) with address, subject and closing |
| Buchkapitel (book chapter) | A chapter of a book or manuscript |
| README | Project description for a software repository |
| Notiz (note) | Short note without structure |

How the text becomes a PDF is described under [Print preview and PDF](../print-and-pdf/).
