---
title: Syncing notes
description: The notes folder can be synced between computers with any file sync or as a Git repository.
order: 4
---

DevMark has no sync service of its own. Since notes are plain files, you sync the notes folder with whatever tool you already use.

## Put the folder into a synced folder

1. Notizen → “Notizordner wählen …“ (choose notes folder).
2. Pick a folder in iCloud Drive, Nextcloud, Dropbox or Syncthing.

On the second computer, choose the same folder.

## As a Git repository

The notes folder can be a Git repository. You commit and push with Git itself; links are relative Markdown links and also work when viewed on GitHub.

## Changes from outside

When another program or the sync has changed something, DevMark picks it up as soon as its window becomes active again.
